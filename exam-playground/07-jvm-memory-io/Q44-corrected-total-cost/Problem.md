# Q44-corrected-total-cost

A billing application calculates the total cost of purchased items. Due to an error in the 
existing logic, the total is incorrectly calculated. 
The correct formula is: 
Total = Quantity × Price 
Write a Java program with the corrected logic to calculate the total cost of each item and 
print the final total. 
Input Format 
The first line contains N. 
Each of the next N lines contains quantity and price. 
Output Format 

--- PAGE 38 ---
Print the total cost of all items. 
Code Constraints 
1 ≤ N ≤ 100 
1 ≤ Quantity ≤ 1000 
1 ≤ Price ≤ 100000 
Sample Input 
3 
2 100 
5 50 
3 200 
Sample Output 
1350
