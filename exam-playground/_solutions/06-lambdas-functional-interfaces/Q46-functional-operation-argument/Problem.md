# Q46-functional-operation-argument

A financial application needs to apply different operations to an amount. The supported 
operations are addition of a fixed value and multiplication by a fixed value. 
Write a Java program that passes a functional interface as an argument to a method. The 
method should apply the received operation to the given amount. 
Input Format 
The first line contains the amount. 
The second line contains the operation value. 
The third line contains the operation type: ADD or MULTIPLY. 
Output Format 
Print the resulting amount. 
Code Constraints 
0 ≤ Amount ≤ 100000 
0 ≤ Value ≤ 1000 
Sample Input 
1000 
50 
ADD 
Sample Output 
1050
