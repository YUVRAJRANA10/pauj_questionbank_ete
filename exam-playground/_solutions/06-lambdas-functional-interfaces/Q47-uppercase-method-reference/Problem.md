# Q47-uppercase-method-reference

A student-information system stores the names of students. The system needs to print each 
student name in uppercase. 
Write a Java program using a method reference to refer to the appropriate String method for 
converting each name to uppercase. 
Input Format 
The first line contains N. 
The second line contains N student names separated by spaces. 
Output Format 
Print all student names in uppercase separated by spaces. 

--- PAGE 40 ---
Code Constraints 
1 ≤ N ≤ 100 
Each name contains only alphabetic characters. 
Sample Input 
3 
amit neha rahul 
Sample Output 
AMIT NEHA RAHUL
