# Q64-subject-average-marks

A university maintains examination marks for different subjects. The examination 
department wants to calculate the average marks obtained in each subject. 
Write a MySQL query that groups the records by subject and calculates the average marks. 
Input Format 
The first line contains an integer N. 
The next N lines contain: 
student_id subject marks 
Output Format 
Display: 
subject average_marks 
with the average rounded to two decimal places. Display subjects in alphabetical order. 
Constraints 
• 
1 ≤ N ≤ 100  
• 
0 ≤ marks ≤ 100  
• 
Subject names contain no spaces.  
Sample Input 
6 
101 Java 80 
102 Java 90 
103 DBMS 70 
104 DBMS 80 

--- PAGE 54 ---
105 Java 100 
106 DBMS 90 
Sample Output 
DBMS 80.00 
Java 90.00
