# Q66-salary-above-average

A company wants to identify employees whose salary is greater than the average salary of all 
employees. 
Write a MySQL query using a nested query to find these employees. 
Input Format 
The first line contains an integer N. 
The next N lines contain: 
employee_id employee_name salary 
Output Format 
Display: 
employee_name salary 
for employees whose salary is greater than the overall average salary. Display them in 
descending order of salary. 
Constraints 
• 
1 ≤ N ≤ 100  
• 
Salary is a positive integer.  
• 
Employee names contain no spaces.  
Sample Input 
5 
101 Amit 40000 
102 Neha 60000 
103 Rahul 50000 
104 Simran 80000 
105 Karan 30000 
Sample Output 

--- PAGE 56 ---
Simran 80000 
Neha 60000
